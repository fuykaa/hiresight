Sebagian besar perusahaan menyaring lamaran dengan Applicant Tracking System sebelum recruiter membacanya. Tanpa keyword yang tepat dan format yang ramah mesin, CV terbaik sekalipun bisa gagal di tahap awal.

ID ↔ EN

Bilingual gap

Tentang Aplikasi

HireSight.

Web-based ATS checker. Upload CV, tempel job description, lalu AI kami mengekstrak fakta dan algoritma Go menghitung skor — semuanya berjalan asynchronous via goroutine, hasil ditampilkan secara real-time.

Langkah 01

Upload CV kamu

PDF, maks 5MB. Disimpan di Azure Blob Storage, di-extract via Azure Document Intelligence.

Langkah 02

Tempel Job Description

Posisi + JD lengkap. Backend trigger goroutine async & langsung return 202 Accepted.

Langkah 03

Dapatkan analisis AI

Frontend polling tiap 2 detik → tampilkan ATS Score, Keyword Score, Format Score + saran.

Penerapan Teknologi · Jaringan Komputer

Client–Server, REST, & Nginx.

01 · Arsitektur

Client–Server 3-Tier

Browser sebagai client → Nginx sebagai reverse proxy → Frontend (Next.js) & Backend (Go) sebagai application servers → PostgreSQL sebagai data tier.

02 · Protokol HTTP/HTTPS

REST API + JSON

FE → BE pakai fetch() dengan metode GET / POST / PATCH / DELETE. Status code dipakai semantik: 200, 201, 202 Accepted (analisis async), 401 (JWT invalid).

03 · Nginx Reverse Proxy

Single Entry :80

Routing /api/* → backend:8081, selain itu → frontend:3000. Plus static cache 1 tahun untuk asset Next.js (/_next/static/*).

Penerapan Teknologi · Kecerdasan Buatan

AI sebagai "mata", Go sebagai "otak".

Groq Llama 3.3 70B hanya bertugas mengekstrak fakta dari CV + JD. Penilaian kuantitatif sepenuhnya dilakukan pure-Go agar deterministik, reproducible, & bebas hallucination.

Layer 01 — AI Engine

Groq · Llama 3.3 70B

Ekstraksi keyword dari JD (required vs preferred)

Identifikasi keyword di CV + lokasi section

Deteksi section headers (Experience, Education, Skills…)

Deteksi bahasa (English / Mixed / Indonesian)

Klasifikasi profil: Experienced · Fresh Graduate · Career Changer

POST groq.com/openai/v1/chat/completions
model: llama-3.3-70b-versatile
response_format: { type: "json_object" }

Layer 02 — Deterministic Scorer

Pure Go · scorer.go

keyword_score = required_found / total_required × 70%
+ preferred_found / total_preferred × 30%

section_score = std_sections / (std + non_std) × 100
language_score = EN→100 · MIXED→60 · ID→30
format_score = section × 60% + language × 40%

ats_score = keyword × 65% + format × 35%

Bobot 70/30 dan 65/35 mengacu pada riset required keyword sebagai knockout filter dominan di ATS nyata — bukan angka asumsi.
